# DevOps Práctica

## Estrategia de Ramas

Este repositorio utiliza una estrategia de **Feature Branches** (Ramas de Características).

Cada nueva funcionalidad se desarrolla en una rama separada:
- `feature/frontend`: Página web estática
- `feature/docker`: Dockerfile y pipeline CI/CD
- `feature/docs`: Documentación del proyecto

## Propósito

Implementar un ciclo completo de DevOps con control de versiones,
automatización CI/CD con GitHub Actions y despliegue en AWS.
